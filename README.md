# Managerium demo archive

Authenticated Firecrawl archive of the Managerium demo at `https://mgm.ibos.io/`, captured on 2026-09-13.

The archive contains 105 discovered application routes, 146 tab states, 114 table snapshots, 7,710 control records, and 63 opened create/new views. No records were submitted or modified during collection.

See [MANAGERIUM_SCRAPE_REPORT.md](MANAGERIUM_SCRAPE_REPORT.md) for the coverage report, data-file guide, and known extraction gaps. Raw and flattened artifacts are stored in [`.firecrawl/`](.firecrawl/).

This repository contains demo business and contact data and is intended to remain private. Browser-session credentials and live authentication tokens were removed before commit.
